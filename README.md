# Sirius Security — Site web

Site vitrine professionnel pour Sirius Security, inspiré de la structure de [3isecurity.be](https://3isecurity.be/), avec l’identité visuelle Sirius (bleu `#0A84C5`, noir, argent).

## Lancer en local

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```

## Assets

- `public/img/logo.png` — logo original
- `public/img/logo-nav.png` — logo adapté fond sombre (header / footer)
- `public/img/banner.png` — bannière hero
